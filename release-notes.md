## InteractiveMenu

Радиальное меню-«дерево» для Windows: зажми хоткей, и в центре экрана появится шар с ветками к твоим командам.

### Что внутри
- Меню «дерево растёт»: наводишь на категорию, и из неё вырастают новые ветки
- Плавная отрисовка: фон из снимка экрана с размытием, рендер целиком на видеокарте
- Кнопки: открыть файл, папку, программу или ссылку, команда cmd, комбинация клавиш, звук и медиа, блокировка, сон, питание
- Сценарии: несколько действий по одной кнопке
- Тёмное окно настроек с редактором дерева и кнопкой «Проверить меню»
- Автообновление из GitHub Releases с откатом, если новая версия не запустилась

### Установка
```powershell
irm https://raw.githubusercontent.com/Reuz0201/InteractiveMenu/main/install.ps1 | iex
```
Или скачай `InteractiveMenu-win-x64.zip`, распакуй и запусти `InteractiveMenu.exe` (нужен .NET 8 Desktop Runtime).
