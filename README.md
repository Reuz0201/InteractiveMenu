# InteractiveMenu

Радиальное меню-«дерево» для Windows. Зажимаешь хоткей, и в центре экрана появляется шар
с ветками к категориям. Наводишь на категорию, и из неё вырастают новые ветки. Отпускаешь хоткей
над кнопкой, и кнопка срабатывает.

## Установка

```powershell
irm https://raw.githubusercontent.com/Reuz0201/InteractiveMenu/main/install.ps1 | iex
```

Скрипт ставит приложение в `%LOCALAPPDATA%\Programs\InteractiveMenu`, создаёт ярлык в «Пуске»
и при необходимости доставляет .NET 8 Desktop Runtime. Ещё можно скачать zip со страницы
[Releases](https://github.com/Reuz0201/InteractiveMenu/releases), распаковать и запустить `InteractiveMenu.exe`.

Дальше приложение обновляется само: раз в несколько часов проверяет GitHub Releases,
ставит новую версию и откатывается назад, если она не запустилась.

## Управление

| Что | Как |
|---|---|
| Открыть меню | зажать **Alt + Q** (меняется в настройках) |
| Выполнить кнопку | навести мышку и отпустить хоткей |
| Отмена | отпустить хоткей на пустом месте или нажать Esc |
| Режим кликов | коротко тапнуть хоткей, после чего меню остаётся открытым и работает мышкой |
| Назад на уровень | ПКМ или Backspace |
| Настройки | двойной клик по иконке в трее или шарик «Настройки» в меню |

## Что умеют кнопки

Каждая кнопка — это список действий, которые выполняются по порядку. Несколько действий
в одной кнопке и есть сценарий.

- открыть файл, папку или программу (с аргументами)
- открыть ссылку
- команда cmd (скрыто или в окне)
- нажать комбинацию клавиш (`Ctrl+Shift+Esc`, `Win+D`…)
- звук: вкл/выкл, громче, тише; медиа: пауза, следующий, предыдущий
- пауза между шагами)
- блокировка, сон, перезагрузка, выключение
- открыть настройки меню

## Разработка

```bat
dotnet run
```

Локальная сборка имеет версию `0.0.0-dev` и не обновляется. Релизы собирает GitHub Actions
на каждый пуш в `main`. Версия считается как `version.txt` плюс число коммитов после его последней правки:
поменял `version.txt` на `1.1`, и следующий релиз будет `1.1.0`.

Конфиг и лог лежат в `%AppData%\InteractiveMenu`.

```
App.xaml(.cs)              — запуск, трей, хоткей, обновления
Models/                    — MenuNode (шарик), ActionStep (действие), AppConfig
Services/KeyboardHook.cs   — глобальный хук клавиатуры (ловит нажатие и отпускание)
Services/ActionRunner.cs   — выполнение действий
Services/ScreenCapture.cs  — снимок экрана для фона меню
Services/Updater.cs        — автообновление из GitHub Releases
Views/MenuWindow           — само меню (шарики, ветки, анимации)
Views/SettingsWindow       — тёмное окно настроек
Views/Theme.xaml           — стили тёмной темы
```
